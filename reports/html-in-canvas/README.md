# HTML-in-Canvas: границы возможного

44 слайда Shower, 26 слайдов с кодом, ориентировочный тайминг 38 минут (без вопросов).

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000
```

- Презентация: http://localhost:8000/reports/html-in-canvas/
- Демо: http://localhost:8000/reports/html-in-canvas/demo/
- Проверка запасного режима: http://localhost:8000/reports/html-in-canvas/demo/?fallback

Shower: клик по слайду открывает показ, стрелки переключают слайды, Esc возвращает список. Редактор открывается отдельной вкладкой, чтобы горячие клавиши Shower не мешали вводу.

## Файлы

- `index.html` — слайды, скрытые `footer.notes` и локальные зависимости Shower/highlight.
- `styles.css` — оформление по мотивам `temporal`, фоны из `src/picture/sb-background`.
- `speaker-notes.md` — полный разговорный текст для 44 слайдов, ориентировочный тайминг на 38 минут, действия в демо и готовые реплики для запасного режима.
- `sources.md` — первичные источники и оговорки.
- `demo/` — учебный редактор без сборки и внешних библиотек.

## Границы демо

Один изменяемый текстовый блок, фон, круг и перекрывающая фигура; координаты, ширина и угол задаются ползунками. PNG экспортируется после отрисовки. Нет полноценной модели rich-text документа, drag-and-drop, истории, сохранения проекта и маршрутизации взаимодействия с нарисованной фигурой. Поведение выделения, фокуса и окклюзии предназначено для исследования.

Демо использует актуальные `content="drawable"`, `drawable`, `drawElementImage` и автоматическую геометрию 2D. Наличие методов проверяется вместе с пробой рисования. При несовместимости включается честный DOM-просмотр без экспорта. Legacy `layoutsubtree` намеренно не подмешивается.

## Проверка в этой сессии

Проверены структура 44 слайдов, локальные ссылки, отсутствие inline-стилей, синтаксис JavaScript, открытие Shower и границы блоков в браузере. Просмотрены титул и слайды с кодом. Во встроенном браузере сработал fallback. Нативный путь HTML-in-Canvas, ввод на холсте и экспорт PNG не подтверждены запуском: встроенный браузер не предоставляет API, управление установленным Chrome недоступно без разрешений Computer Use. Перед выступлением выполнить три сценария из заметок в целевом Chrome.

## Ошибка Tainted canvases при открытии с диска

Не открывайте `demo/index.html` через `file://`. Фон с диска может сделать canvas недоступным для экспорта. Запускайте локальный HTTP-сервер из корня репозитория и используйте адрес демо выше. В демо добавлена проверка `file:` до загрузки ресурсов, а фон загружается в CORS-режиме. Ошибка загрузки фона больше не игнорируется.
