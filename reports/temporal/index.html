Москва и UTC+3 — не одно и то же

Temporal.ZonedDateTime.from(
  "2010-07-01T12:00[Europe/Moscow]"
).toInstant().toString(); // "2010-07-01T08:00:00Z"

Temporal.ZonedDateTime.from(
  "2010-07-01T12:00[+03:00]"

[+03:00] — постоянное смещение для любой даты, без перевода часов.

03 / Новая модель Temporal

Сколько длилась встреча?

// start — Instant из предыдущего примера
const end = start.add({ hours: 1, minutes: 30 });
const elapsed = start.until(end);
elapsed.toString(); // "PT5400S"
elapsed.total({ unit: "minutes" }); // 90

end.since(start).total({ unit: "minutes" }); // 90
end.until(start).total({ unit: "minutes" }); // -90

start.until(end) и end.since(start) → 90 минут.
Меняем начало и конец местами → −90 минут.
