# AGENTS.md — Инструкции для ИИ по работе со Shower-презентацией

Этот файл содержит строгие правила разработки, сборки и стилизации для ИИ-ассистентов. Не нарушайте структуру HTML-слайдов и экосистему Shower.

## Специфика проекта
Проект представляет собой презентацию на движке **Shower.js**.
- Основной файл разметки: `index.html` (или файлы в папке `slides/`, если настроена сборка).
- Темы оформления: используются стандартные темы Shower (`ribbon` или `bright`) или кастомные CSS/SCSS стили.

## Сборка и запуск
Инструменты управления пакетами и команды для работы с проектом:
- Установка зависимостей: `npm install` (или `pnpm install` / `yarn install` в зависимости от lock-файла).
- Локальный сервер разработки (с автоперезагрузкой): `npm start` или `npm run dev`.
- Финальная сборка/оптимизация: `npm run build`.

## Архитектура слайдов Shower
Каждый слайд должен строго соответствовать структуре Shower:
1. Каждый слайд — это секция `<section class="slide">`.
2. Внутри слайда обязательно должен быть заголовок `<h2>`.
3. Для пошаговых элементов списков или блоков используйте класс `next` (Shower скрывает их и показывает по очереди при клике/нажатии клавиш).
4. Кастомные стили должны находиться в отдельном файле (например, `styles/custom.css`), не пишите инлайн-стили в HTML.

Пример правильной разметки слайда:
```html
<section class="slide" id="example-slide">
    <h2>Заголовок слайда</h2>
    <p>Обычный текст или описание.</p>
    <ul>
        <li>Постоянный пункт</li>
        <li class="next">Появляющийся пункт 1 (класс next)</li>
        <li class="next">Появляющийся пункт 2</li>
    </ul>
    <figure>
        <img class="cover" src="images/picture.jpg" alt="Фоновое изображение">
    </figure>
</section>
```

## Важные правила для ИИ
- **Никогда не удаляйте корневой класс `.shower`** у тега `<body>` и контейнеры плагинов (например, прогресс-бар, счетчик слайдов).
- **Изображения:** Для фоновых картинок на весь слайд используйте класс `cover` (пример: `<img class="cover" src="...">`). Для подгонки по ширине/высоте используйте `w` или `h` классы Shower.
- **Двухколоночный текст:** Для разделения контента на колонки используйте встроенные возможности темы или стандартный CSS Grid/Flexbox внутри секции слайда.
- **Режим докладчика:** Помните, что теги `<footer class="notes">` внутри слайда используются для заметок спикера и не отображаются на основном экране. Добавляйте туда полезный контекст для доклада, если вас об этом просят.
- **Чистота кода:** Не подключайте тяжелые сторонние JS-библиотеки ради простых анимаций, используйте CSS-переходы.
